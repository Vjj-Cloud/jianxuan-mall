## 你要写的 4 个文件

路径统一在 `src/main/java/com/jack/jianxuan/` 下。

### 1. `common/Result.java`

统一返回体，泛型。

```json
{ "code": 200, "message": "ok", "data": {} }
```

要求：
- 字段：`code`、`message`、`data`
- 静态方法：`Result.ok()`、`Result.ok(T data)`、`Result.fail(int code, String message)`
- 用 Lombok `@Data` 省 getter/setter

> 提示：泛型类上别加 `@Data` 又能链式，简单点，`@Data` + 三个字段 + 静态工厂就够了。

### 2. `common/BusinessException.java`

自定义业务异常，继承 `RuntimeException`。

要求：
- 携带 `code` 字段（默认 400）
- 构造方法：`BusinessException(String message)`、`BusinessException(int code, String message)`

### 3. `common/GlobalExceptionHandler.java`

`@RestControllerAdvice`，处理三类异常：

| 异常 | 返回 code | 说明 |
|---|---|---|
| `BusinessException` | 异常自带 code | 业务错误 |
| `MethodArgumentNotValidException` | 400 | 参数校验失败，取第一条字段错误消息 |
| `Exception` | 500 | 兜底，日志打印堆栈，返回"系统繁忙" |

> 注意：兜底方法里**不要把完整堆栈返回给前端**，只记日志。

### 4. `controller/PingController.java`

```java
@RestController
@RequestMapping("/api")
public class PingController {
    @GetMapping("/ping")
    public Result<String> ping() {
        return Result.ok("pong");
    }
}
```
